# دليل المشتري: تشغيل نسختك الخاصة من منصة واتساب للأعمال

هذه النسخة ملكك بالكامل: تديرها بنفسك وتضيف مستنداتك وقوالبك وموظفيك بدون أي تدخل من البائع.

## أول تشغيل (دقيقتان)

1. افتح رابط المنصة الذي استلمته من البائع.
2. ستظهر لك شاشة "مرحبًا بك! لنبدأ الإعداد":
   - **اسم النشاط**: يظهر في واجهة المنصة بدل أي اسم آخر.
   - **حساب المدير**: اسم مستخدم وكلمة سر لك أنت (صلاحيات كاملة).
   - **بيانات ميتا (اختيارية الآن)**: يمكن تركها فارغة وإدخالها لاحقًا من صفحة "المطورون (API)".
3. اضغط "إنشاء الحساب وبدء العمل" — ستدخل المنصة مباشرة.

> هذه الشاشة تظهر مرة واحدة فقط. بعد إنشاء المدير تختفي نهائيًا.

## ربط رقم الواتساب الخاص بك (ميتا)

تحتاج تطبيق WhatsApp Business API من [developers.facebook.com](https://developers.facebook.com):

1. أنشئ تطبيقًا وأضف منتج WhatsApp، واحصل على:
   - **Phone Number ID**
   - **WhatsApp Business Account ID**
   - **Access Token دائم** (System User Token)
2. في المنصة: صفحة **المطورون (API)** ← بطاقة "ربط واتساب للأعمال":
   - الصق القيم الثلاثة، واختر **Verify Token** (أي كلمة سر من عندك)، واحفظ.
3. في لوحة ميتا (إعدادات Webhook لتطبيقك):
   - **Callback URL**: `https://رابط-منصتك/webhook`
   - **Verify Token**: نفس الكلمة التي حفظتها في الخطوة 2.
   - فعّل الاشتراك في حقل **messages**.
4. أرسل رسالة تجريبية لرقمك — ستظهر في صندوق الوارد فورًا.

## ماذا تدير بنفسك من لوحة التحكم؟

- **المحادثات**: صندوق وارد موحد مع الردود الجاهزة والوسائط.
- **جهات الاتصال**: استيراد Excel/CSV وتصنيف.
- **القوالب**: إنشاء قوالب رسائل وإرسالها لميتا للاعتماد.
- **الحملات**: إرسال جماعي بإيقاع آمن وإيقاف تلقائي عند الأخطاء.
- **البوت**: ردود تلقائية وقواعد حسب الكلمات المفتاحية.
- **الموظفون**: حسابات بصلاحيات (مدير/موظف) وربط كل موظف بقسم.
- **النسخ الاحتياطي**: تنزيل نسخة كاملة من بياناتك في أي وقت (من لوحة التحكم).

## الدومين الخاص بك (اختياري)

إذا أردت رابطًا باسم نشاطك مثل `wa.yourbusiness.com`:

1. اشترِ الدومين من أي مسجّل (Namecheap, GoDaddy, ...).
2. في لوحة Render الخاصة بخدمتك: **Settings ← Custom Domains ← Add**.
3. أضف سجل CNAME في لوحة الدومين يشير إلى رابط Render.
4. Render يصدر شهادة HTTPS تلقائيًا خلال دقائق.

## الاستضافة على خادمك الخاص (اختياري)

المنصة تعمل على أي خادم فيه **Node.js 20 أو أحدث**:

```bash
git clone <رابط المستودع الذي استلمته>
cd wa-inbox
git checkout saas
npm install
npm start
```

- قاعدة البيانات SQLite تُنشأ تلقائيًا في مجلد `data/` — انسخ هذا المجلد احتياطيًا دوريًا.
- لا تحتاج أي متغيرات بيئة: كل شيء يُدخل من شاشة الإعداد أو صفحة المطورين.
- خلف Nginx/Apache فعّل التمرير (reverse proxy) للمنفذ 3000 مع HTTPS.

## ملاحظات مهمة

- توكن ميتا لا يظهر كاملًا بعد الحفظ (آخر 4 أرقام فقط) ولا يدخل في النسخ الاحتياطية.
- النسخ الاحتياطية لا تتضمن كلمات مرور الموظفين.
- إذا نسيت كلمة سر المدير: من يملك وصولًا للخادم يمكنه حذف ملف قاعدة البيانات وإعادة الإعداد (تُفقد البيانات)، أو تواصل مع البائع.
